# Nonprofit Operations Dashboard 2026

## Mock Data Portfolio Project inspired by Dress for Success operational reporting

This project is an interactive Excel dashboard built using mock nonprofit operations data. The dashboard tracks service delivery, income, donations, volunteer contribution, marketing outreach, and Work Experience Volunteer programme outcomes.

The purpose of this project is to demonstrate practical reporting, dashboarding, and data analysis skills using Excel.

## Project Objectives

- Clean and structure daily operational data into a dashboard-ready format
- Track key service delivery metrics such as styling registrations, completed services, and completion rate
- Analyse income, donations, re-donations, volunteer hours, and WEV employment outcomes
- Build an interactive dashboard using PivotTables, charts, KPI cards, and slicers
- Use Quarter, Month, and Day slicers to allow flexible analysis

## Dashboard Features

- KPI cards for income, completion rate, completed styling services, WEV employment outcomes, donations, re-donations, volunteer count, and volunteer hours
- Monthly income trend chart
- Completed styling services by month
- Client gender breakdown
- Work Experience Volunteer programme outcomes
- Donations vs re-donations analysis
- Marketing outreach vs engagement comparison
- Interactive slicers for Quarter, Month, and Day

## Tools Used

- Microsoft Excel
- PivotTables
- Pivot Charts
- Slicers
- KPI Cards
- Data Cleaning
- Dashboard Design

## Dataset

This project uses mock data created for portfolio purposes. No confidential, personal, or official organisational data is included.

## Key Insights Demonstrated

- Monthly income and service delivery trend analysis
- Styling service completion performance
- Volunteer contribution tracking
- Donation and re-donation monitoring
- WEV programme outcome reporting
- Marketing outreach and engagement comparison
